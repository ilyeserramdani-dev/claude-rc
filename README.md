# claude-rc
Site internet

## Structure

- `index.html` : page d'accueil (accueil, services, à propos, contact)
- `css/style.css` : styles (responsive, thème clair/sombre automatique)
- `js/main.js` : menu mobile, formulaire de contact, année du pied de page

## Utilisation

Ouvrez simplement `index.html` dans un navigateur, ou servez le dossier avec n'importe quel serveur statique :

```bash
python3 -m http.server 8000
```

Pensez à remplacer les textes d'exemple (« Service 1 », « Mon Site », etc.) par votre contenu.
